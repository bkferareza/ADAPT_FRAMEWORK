# Planning Rules

## Status
ACTIVE

## Purpose
Defines how accepted source truth becomes milestone recommendations.

## Current State
No milestone is approved.

## Planning Reads
- accepted source truth
- milestone objective
- workcell registry
- capacity model
- lane assignment matrix
- dependency map
- open blockers
- open gaps
- carry-over work

## Planning Workflow
1. Receive milestone objective.
2. Analyze requirement scope.
3. Slice work into bounded chunks.
4. Sequence dependencies.
5. Map work to onboarded workcells.
6. Check capacity and overextension.
7. Produce milestone and workcell roadmap recommendations.
8. Handoff plan to Director for approval.

## Planning Rule
Planning recommends. Director approves.

## Current Constraint
Planning cannot assign real implementation work until technology decisions and workcell onboarding exist.
