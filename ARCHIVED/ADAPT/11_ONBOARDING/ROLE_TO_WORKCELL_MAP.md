# Role To Workcell Map

## Status
ACTIVE

## Purpose
Maps supported roles to future workcell types.

## Role Map
| Role | Workcell Type | Typical Scope | Current Status |
|---|---|---|---|
| Director | DIRECTOR | Control plane, source truth, routing, approval, consolidation | Director Lane scaffold exists |
| Integrator | INTEGRATOR | Cross-lane contracts, integration readiness, merge readiness | INTEGRATOR_BRIAN active |
| Backend Developer | BACKEND | Backend behavior, data, APIs, services after technology decision | BACKEND_BRIAN active |
| Frontend Developer | FRONTEND | User flows, UI behavior, state, client behavior after technology decision | FRONTEND_BRIAN active |
| QA | QA | Independent validation and defect evidence | QA_BRIAN active with independence constraint |
| Planning | PLANNING | Milestones, slices, capacity, roadmaps | Not onboarded |
| Context Steward | CONTEXT_STEWARD | Context packs, deltas, indexes, summaries | Not onboarded |
| Janitor | JANITOR | Cleanup, archive, stale artifact detection, compaction | Not onboarded |
| Challenge Reviewer | CHALLENGE | 10th Man review and failure-mode challenge | Not onboarded |

## Rule
The map is role guidance only. It does not create workcells or assign work.
