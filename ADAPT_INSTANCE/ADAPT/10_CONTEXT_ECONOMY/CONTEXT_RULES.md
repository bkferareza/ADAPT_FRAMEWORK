# Context Rules

1. No agent reads the whole project by default.
2. Every bounded execution receives an atomic Context Pack.
3. Every execution returns a Context Delta.
4. Context must be current, authoritative, relevant, and no larger than needed.
5. Superseded or archived material is excluded unless explicitly needed.
6. Missing required context creates `GAP-T11 Context Gap`; it is never guessed.
7. XL jobs require splitting or Director/human approval.
