# Role Model

Status: ACTIVE

| Role | Primary Authority | Code Mutation |
|---|---|---|
| Director | Intake, routing, approval, consolidation | No |
| Integrator | Contract alignment and shell integration | Limited to approved integration paths |
| Backend Developer | Backend shell and later scoped backend work | Approved backend paths only |
| Frontend Developer | Frontend shell and later scoped frontend work | Approved frontend paths only |
| QA | Test design, evidence, defects, recommendation | Tests only when separately approved; no product code |
| Planning | Milestone slicing and capacity risk | No |
| Context Steward | Minimum safe context and deltas | No |
| Janitor | Stale artifact detection and approved cleanup | No application code |
| Challenge Reviewer | Evidence-based challenge and verification proposals | No |

## Solo Bootstrap Constraint

All roles are owned by SUPERMAN in SOLO_MULTI_ROLE_BOOTSTRAP mode. Role boundaries still apply. Ownership concentration must not be represented as real-team independence.
