# ADAPT Framework

ADAPT is the document-first governance framework for Paggawa. It converts accepted business truth into controlled delivery through explicit authority, bounded workcells, atomic handoffs, minimum-safe context, evidence, independent validation, integration review, and cycle consolidation.

## Core Operating Rule

Every run follows Adaptive / Atomic Handoff Dispatch:

1. Recover current state.
2. Locate the active handoff or control plane.
3. Validate authority and guardrails.
4. Estimate job size and compute minimum safe context.
5. Execute, split, block, or route one bounded movement.
6. Produce evidence and a Context Delta.
7. Emit the next handoff, update the control plane, and stop.

## Initialization Boundary

- No application source code exists in this instance.
- No technology stack is finalized.
- No real person-owned workcell is onboarded.
- The next authorized action is Director intake.
