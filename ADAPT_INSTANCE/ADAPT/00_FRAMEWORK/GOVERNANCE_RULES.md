# Governance Rules

1. Source truth must be explicit, versioned, and preserved.
2. Conversation and Memory Bank notes are not authority.
3. Director Lane controls movement but cannot mutate application code.
4. Workcells execute only within approved scope and active handoffs.
5. Developer self-validation is not QA signoff.
6. Handoffs must be atomic and carry minimum-safe context.
7. Claims close only on evidence.
8. Gaps and blockers must be recorded and routed.
9. Planning recommends; Director approves.
10. Janitor may archive or compact but must not casually delete truth.
11. Challenge Lane may challenge with evidence or a testable failure mode.
12. Every bounded run emits a Context Delta and stops.
