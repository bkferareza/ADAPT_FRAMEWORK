# Governance Rules

Status: ACTIVE

1. SOURCE_TRUTH_V0.1 is the current business authority.
2. Director controls movement and acceptance but cannot mutate application code.
3. Workcells mutate only their allowed paths and only under an authorized handoff.
4. Developer self-validation is not independent QA signoff.
5. QA_SUPERMAN is constrained because the same human owns implementation roles.
6. Integrator checks contracts and joining; Integrator is not QA or Director.
7. Missing decisions become gaps or open questions.
8. No production credentials, secrets, database, authentication, or cloud resources may be created in M01.
9. M01 permits project shell scaffolding only.
10. Completion claims require repository evidence.
