# Onboarding Rules

Onboarding requires an explicit `Onboard <Name> as <Role>` command and approval.

Before creating a workcell, verify Director Lane, Source Truth, Workcell Registry, supported role, useful role context, and bounded scope. Create identity, scope contract, agent team, roadmap, task register, evidence log, handoffs, blockers, and Context Deltas.

Do not invent people, randomly assign work, mutate application code, or create implementation tasks without approved source truth and planning authority.
