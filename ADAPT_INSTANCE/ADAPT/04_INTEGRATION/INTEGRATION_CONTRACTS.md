# Integration Contracts

Candidate contracts requiring later approval:

1. Mobile and Quest share job, worker, response, match, completion, review, and reputation semantics.
2. Discovery exposes approximate location only.
3. Match acceptance is the only event that unlocks coordination details.
4. Only matched jobs can be completed; completion is idempotent.
5. Review follows completion and updates transparent reputation fields.
6. Barangay-assisted records obey the same privacy and status rules as mobile records.
