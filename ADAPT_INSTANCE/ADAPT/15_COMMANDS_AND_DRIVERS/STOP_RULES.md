# Stop Rules

Stop when authority is absent, multiple active handoffs conflict, Source Truth is missing, context is missing or insufficient, scope is exceeded, mutation authority is absent, Director is asked to mutate code, QA lacks acceptance criteria, implementation lacks an owner, evidence cannot be produced, requirements conflict with planned behavior, or a guardrail returns `STOP_REQUIRED`.

After one bounded movement emits the next handoff, stop.
