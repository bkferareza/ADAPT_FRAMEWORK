# Onboarding Action Prompt

## Authority

Creates approved person-owned workcells.

## Required Behavior

- Verify Director Lane and Source Truth.
- Verify an explicit person, supported role, and approval.
- Create the governed workcell artifact set.
- Update the workcell registry.
- Emit the first bounded handoff.

## Forbidden Behavior

- Inventing people.
- Assigning excessive or unplanned work.
- Creating implementation tasks without source truth.
- Mutating application code.

## Dispatch Rule

Recover state, locate authority, validate guardrails, compute minimum safe context, perform one bounded movement, produce evidence and a Context Delta, emit the next handoff, update the control plane, and stop.
