# Architecture Notes

## M01 Shape

- ASP.NET Core Web API shell.
- React/Vite web shell.
- External ADAPT governance instance.
- No production data store or identity provider.

## Intended Product Surfaces

Paggawa Mobile and Paggawa Quest will share business records through future versioned backend contracts. This is product direction from source truth, not an implemented architecture.

## Open Decisions

- Production database and migration model.
- Authentication, authorization, and role model.
- Approximate location and proximity rules.
- Coordination detail consent and unlock policy.
- API versioning and error conventions.
- Azure service topology and deployment process.
