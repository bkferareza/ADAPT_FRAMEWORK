Status: ACTIVE

Valid examples:

- Initialize ADAPT from requirements
- Promote Paggawa.docx as SOURCE_TRUTH_V0.1
- Run Director intake
- Onboard SUPERMAN as Backend Developer
- Plan milestone M01
- Generate context pack for active handoff
- Run atomic handoff dispatch
- Run integration review
- Run QA validation
- Run janitor pass
- Director consolidate cycle

Invalid commands omit the owner, role, milestone, gap, blocker, authority, or bounded output needed to route work safely.
