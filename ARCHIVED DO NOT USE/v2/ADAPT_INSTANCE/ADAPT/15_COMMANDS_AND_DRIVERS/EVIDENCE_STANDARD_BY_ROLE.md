# Evidence Standard by Role

| Role | Minimum Evidence |
|---|---|
| Director | Decision log, assignments, control plane, consolidation |
| Backend | Requirement trace, changed files, build or developer validation, contract update, handoff |
| Frontend | UI expectation, changed files, build or developer validation, contract update, handoff |
| Integrator | Contract reconciliation, integration report, build status, readiness |
| QA | Test cases, execution evidence, defects, independence statement, recommendation |
| Context Steward | Context pack and delta processing notes |
| Planning | Milestone plan, roadmaps, dependencies, overextension report |
| Janitor | Janitor report, candidates, actions and approvals |
| Challenge | Testable claim, evidence, verification recommendation |
