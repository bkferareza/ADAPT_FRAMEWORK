# Artifact Standards

Status: ACTIVE

Every live artifact should state status, owner or producing role, source references, relevant requirement IDs, evidence, gaps, blockers, and next action when applicable. IDs are stable and use prefixes such as REQ, AC, GAP, BLK, M, WC, TC, IR, JR, and CCR.

Placeholders must be labeled. Superseded material is retained and marked; accepted source truth is never silently replaced.
