# Glossary

| Term | Meaning |
|---|---|
| Paggawa Mobile | Resident and worker mobile-facing web surface |
| Paggawa Quest | Barangay-assisted tablet/desktop surface |

| Context Pack | Minimum safe context for one bounded move |
| Evidence | Verifiable artifact or command result supporting a claim |
| Match | Record created only when a resident accepts a worker response |
