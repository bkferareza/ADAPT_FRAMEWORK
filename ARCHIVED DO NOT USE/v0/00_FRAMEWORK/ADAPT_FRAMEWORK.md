## Purpose
ADAPT is the governance framework for this project. It converts accepted business truth into controlled delivery through Source Truth, Director Lane control, scoped workcells, templates, handoffs, context packs, evidence, validation, planning, onboarding, guardrails, and consolidation.

## Core Principles
- Source truth must be explicit.
- Conversation is not durable authority.
- Repository artifacts are the durable project memory.
- Director Lane controls project movement but does not mutate code.
- Workcells execute only after onboarding and scoped assignment.
- Developer self-validation is not QA signoff.
- QA validation must remain independent.
- Guardrails enforce lane safety.
- Handoffs must be atomic.
- Context must be computed, not dumped.
- No lane closes on confidence; a lane closes only on evidence.
- Gaps and blockers are first-class workflow objects.
- Planning recommends; Director approves.
- Janitor keeps ADAPT sustainable.
- Memory Bank is reference only and is not live authority.
