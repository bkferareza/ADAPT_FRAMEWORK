# Context Budget Policy

| Size | Inputs |
|---|---|
| XS | One command or one small artifact |
| S | One requirement, one scope contract, one template |
| M | Requirement, scope contract, relevant decisions, one contract, active handoff |
| L | Multi-lane context with integration or QA and Director awareness |
| XL | Full lane audit, release review, or major replan; split or require approval |

Context selection must exclude unrelated, stale, superseded, and archived material.
