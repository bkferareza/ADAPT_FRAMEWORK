# Evidence Standard By Role

| Role | Required Evidence |
|---|---|
| Director | Decision log, assignments, control-plane update, certification |
| Backend | Requirement analysis, implementation evidence, contract update, dev validation, handoff |
| Frontend | UI flow, API expectations, implementation evidence, dev validation, handoff |
| Integrator | Contract reconciliation, integration report, build/pipeline status, merge readiness |
| QA | Test cases, execution evidence, defects, signoff recommendation |
| Context Steward | Context Pack and delta-processing notes |
| Janitor | Janitor report, archive candidates, compaction summary |
| Challenge | Challenge report, failure mode, recommended verification |

No claim is accepted solely on confidence.
