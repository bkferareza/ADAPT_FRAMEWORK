# Source Authority Policy

## Authority Order

1. Approved Source Truth and its version log.
2. Approved Director decisions and control-plane state.
3. Approved contracts, plans, and active handoffs.
4. Evidence and validated Context Deltas.
5. Framework and guardrail rules.
6. Memory Bank references and conversation, which are non-authoritative.

Technical choices not stated in that document remain open decisions and must not be inferred as accepted truth.
