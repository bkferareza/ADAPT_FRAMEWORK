# Artifact Standards

- Use Markdown for governance artifacts.
- Use stable IDs for requirements, acceptance criteria, decisions, gaps, blockers, defects, evidence, context packs, and handoffs.
- Record owner, status, source, date, and related authority where applicable.
- Use uppercase controlled status values.
- Mark unknown facts as `TBD`, `UNKNOWN`, `NOT_PROVIDED`, `OPEN_QUESTION`, or `GAP`.
- Preserve superseded truth; do not silently overwrite it.
- Link claims to evidence and next movement to a single handoff.
- Do not place live authority in `14_MEMORY_BANK`.
