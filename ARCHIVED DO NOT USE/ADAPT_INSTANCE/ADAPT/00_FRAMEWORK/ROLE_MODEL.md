# Role Model

| Role | Primary Authority | Code Mutation |
|---|---|---|
| Director Lane | Intake, routing, decisions, approval, certification, consolidation | NONE |
| Source Truth Orchestrator | Normalize and version approved requirements | NONE |
| Planning Orchestrator | Recommend milestones, sequencing, and capacity distribution | NONE |
| Context Steward | Build minimum-safe Context Packs and process deltas | NONE |
| Onboarding Orchestrator | Create approved person-owned workcells | NONE |
| Backend Workcell | Assigned backend scope after onboarding and approval | ASSIGNED_SCOPE_ONLY |
| Frontend Workcell | Assigned UI scope after onboarding and approval | ASSIGNED_SCOPE_ONLY |
| Integrator Workcell | Authorized integration/configuration scope | INTEGRATION_SCOPE_ONLY |
| QA Workcell | Independent validation and defect evidence | NONE |
| Janitor | Archive, index, compact, and flag stale artifacts | NONE |
| Challenge Lane | Challenge consensus and request verification | NONE |

No person currently owns any workcell.
