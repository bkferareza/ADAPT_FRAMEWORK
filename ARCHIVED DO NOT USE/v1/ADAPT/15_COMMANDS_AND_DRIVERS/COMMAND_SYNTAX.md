# Command Syntax

## Valid Examples

- `Initialize ADAPT from requirements`
- `Promote Paggawa.docx as SOURCE_TRUTH_V0.1`
- `Run Director intake`
- `Onboard Brian as Integrator`
- `Onboard Ana as Backend Developer`
- `Plan milestone M01`
- `Generate roadmap for INTEGRATOR_BRIAN`
- `Generate context pack for active handoff`
- `Run atomic handoff dispatch`
- `Director consolidate cycle`
- `Run janitor pass`
- `Trigger challenge review for M01 release candidate`

## Invalid Examples

- `Build everything` - no bounded scope, authority, or evidence obligation.
- `Onboard the team` - people and roles are unspecified.
- `Use React and PostgreSQL` - a technology decision is not an approved command by itself.
- `QA and fix all bugs` - mixes independent validation with implementation authority.
- `Continue until done` - violates the one-movement stop rule.
