# Janitor Rules

## Status
ACTIVE

## Purpose
Keeps ADAPT clean, compact, archived, and usable.

## Janitor Responsibilities
- detect stale artifacts
- identify archive candidates
- flag orphaned tasks
- flag stale blockers
- detect superseded requirements
- compact summaries
- update indexes
- recommend cleanup

## Janitor Limitations
Janitor must not:
- decide product behavior
- delete source truth casually
- override Director decisions
- mutate source code
- create implementation work

No janitor workcell exists.

## Initial Cleanup Guidance

## Future Janitor Outputs
- Janitor report
- stale artifact register
- archive candidates
- compaction summaries
- cleanup recommendations
