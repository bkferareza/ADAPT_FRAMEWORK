## Purpose
Defines practical context limits for future ADAPT execution.

## Budget Guidance
| Job Size | Typical Context | Expected Action |
|---|---|---|
| XS | One status record or decision | Classify, route, or update status |
| S | One small artifact and references | Update a bounded document |
| M | Several related artifacts | Execute a bounded lane task |
| L | Multiple lanes or contracts | Split or prepare detailed context pack |
| XL | Whole-project or ambiguous task | Split first or block |

## Must-Read Rule
Only include artifacts required to complete the handoff safely.

## Do-Not-Read Rule
Exclude unrelated source, stale records, archived artifacts, and future-phase material unless explicitly needed.
