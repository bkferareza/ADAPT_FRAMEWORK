# Paggawa Web Shell

React/Vite shell for the future Paggawa Mobile and Paggawa Quest surfaces.

## M01 Boundary

- No business workflows.
- No API binding.
- No production authentication.
- No maps, chat, payments, GPS, or live tracking.
- No secrets or deployment credentials.

## Commands

```powershell
npm.cmd install
npm.cmd run dev
npm.cmd run build
npm.cmd run lint
```

Business UI work requires a later approved milestone and resolved contracts.
